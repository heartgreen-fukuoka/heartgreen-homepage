# heartgreen-homepage

ハートグリーン合同会社「ヘルパーステーション ハートグリーン」の公式ホームページです。

## 今回の完成版で改善した点
- PC・タブレット・スマートフォンに対応
- ロゴが見切れないヘッダー
- ヒーロー画像を切り取らず、男女が表示される設計
- ボタンとサービス欄の重なりを解消
- マイナスマージンや固定高さに依存しないレイアウト
- フッターのロゴ切れを解消

## 更新方法
1. ChatGPTで修正版ZIPを作成
2. ZIPを解凍
3. GitHubで **Add file → Upload files**
4. ファイルを上書きアップロード
5. **Commit changes**
6. Cloudflareが自動公開
