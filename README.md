# heartgreen-homepage

ハートグリーン合同会社「ヘルパーステーション ハートグリーン」の公式ホームページ用リポジトリです。

## 公開構成
- GitHub: ホームページファイルの保存・変更履歴
- Cloudflare Pages: ホームページの公開
- お名前.com: 独自ドメイン `heartgreen-fukuoka.com`

## 主なファイル
- `index.html`：ページ本文
- `style.css`：デザイン
- `assets/`：画像

## 更新方法
1. ChatGPTで修正済みZIPを作成
2. GitHubのリポジトリで **Add file → Upload files**
3. ファイルをアップロード
4. **Commit changes**
5. Cloudflareが自動公開

## 注意
電話番号、所在地、事業所番号などを変更する際は、公開前に必ず内容を確認してください。
